# bj-hack

A blackjack simulator and strategy tester.

## Initial Requirements

### Game

- Implement a blackjack game with standard Canadian rules:
  - ES10
  - RSA
  - DAS
  - DA2
  - H17
  - 6 decks
  - No dealer hole
- 0 - 6 other players at table
- input bankroll
  - profit/loss only count also

### Simulator

- Simulate set amount of hands with input bankroll
- Implement following strategies:
  - Random
  - Basic
  - Human card counting
  - Perfect card counting
